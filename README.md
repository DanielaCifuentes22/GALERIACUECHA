# Galería Virtual Cuecha

## Descripción del proyecto

Galería Virtual Cuecha es una plataforma web desarrollada para la visualización, promoción y exploración de obras de arte. El proyecto busca ofrecer un espacio digital donde los usuarios puedan conocer diferentes obras, consultar información relacionada con ellas y explorar las diferentes secciones de la galería.

El proyecto cuenta con un frontend desarrollado en React y un backend encargado de proporcionar los servicios necesarios para la comunicación con la base de datos.

## Tecnologías utilizadas

### Frontend
- React
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express

### Base de datos
- MySQL

### Herramientas
- Visual Studio Code
- Git
- GitHub
- Postman

## Estructura del proyecto

El proyecto se encuentra dividido principalmente en:

- **Frontend:** contiene la interfaz y los componentes visuales de la aplicación web.
- **Backend:** contiene el servidor y los servicios de la API utilizados por la aplicación.
- **Base de datos:** almacena la información necesaria para el funcionamiento del sistema.
